# browser-tune

Open-source Chrome + Firefox extension (MV3): performance/memory profiles, declarative domain blocking and safe tab discarding. Local-first, zero telemetry.

## Features (planned)

- Optimization profiles: Balanced, Low Resource, Privacy and Custom
- Declarative domain blocking via `declarativeNetRequest` (no host permissions)
- Safe discarding of inactive tabs with protections
- Local settings, import/export, no telemetry, no account
